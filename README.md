# Сайт-портфолио AI-креатора

Одностраничный лендинг на чистых HTML, CSS и JavaScript. Язык интерфейса — русский.

## Краткий план сайта

1. **Главный экран** — кто вы, что делаете, кнопки «Обсудить идею» и «Посмотреть работы».
2. **О специалисте** — роль AI-креатора и польза для бизнеса.
3. **Услуги** — фотосессии, модели, видео, мультфильмы, реклама, поздравления.
4. **Как проходит работа** — пять шагов от знакомства до готовых файлов.
5. **Проекты** — три карточки-заготовки без вымышленных результатов.
6. **Преимущества** — запуск, подход, коммуникация, ИИ, поддержка.
7. **Заявка** — имя, способ связи, описание задачи + переход в Telegram.
8. **Подвал** — имя, контакты, ссылка на Telegram.

Стиль: светлый фон, графитовый текст, фуксия и розовый, карточки с мягкой тенью.

## Структура файлов

```
landing-page-ai/
├── index.html    — разметка всех разделов
├── styles.css    — оформление и адаптив
├── script.js     — меню, плавный скролл, проверка формы
└── README.md     — этот файл
```

## Как открыть

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python -m http.server 8080
```

Затем перейдите на `http://localhost:8080`.

## Поведение кнопок

- Навигация и кнопки героя плавно прокручивают к разделам.
- Ссылки Telegram открывают чат в новой вкладке.
- Форма не отправляется, пока не заполнены обязательные поля.
- При успешной проверке открывается Telegram с готовым текстом заявки.
